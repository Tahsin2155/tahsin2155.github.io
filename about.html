I'm 17, still in school, figuring out my life (with a fear of AI replacing me). I spend most of my free time on my computer, doing crawzy shit. "Self-taught programmer" wasn't planned - it just sort of happened... Programming makes me feel like a god of this virtual world; I can make them do whatever I want. I build things really badly, at first ;), then less badly, and I keep improving and learning (sometimes or maybe a little bit more often, I hit up AI as well for help, uk!).....

No big plan, honestly. Most things I build start with a "wait, can I actually make this work?" and then I keep poking at it until it does, or until boards remind me I have other things to do. Half the time I'm reading docs I don't fully get yet and figuring it out as I go.

Yes, I know, I'm scared of AI (sometimes) and I use it to build things. Don't judge me! I'd rather say it straight than pretend I did everything alone. Most of the things on this site are something I actually built, planned or learned, with the help of AI.

When I'm not staring at a code editor, I'm trying to get into the MCU, and it's not as easy as it sounds. I started really late, so the backlog is huge, and that's honestly what makes getting in so hard. I'm already a fan of F1: For Constructor I support RedBull, but for Drivers I support Max Verstappen (Mad Max) and Charles Leclerc (Banana Leclerc). I follow it every race week, and if I can't watch a race I still make sure I'm up to date.

This site is basically my little corner of the internet: the stuff I've made, how I ended up here, and whatever I'm figuring out next. Scroll down for the full story, from Minecraft redstone to... whatever Handoff turns out to be.

My Coding Journey

SEPTEMBER 2026
Handoff
Started Handoff, a desktop automation agent that combines Google's Gemini computer-use model with PyAutoGUI to operate a Windows PC. Experimental.
AUGUST 2026 • FIRST PUBLISHED FLASK PROJECT
Zipline
Started Zipline, a Flask app for moving files between my own devices, which grew into a small personal drive with notes.
MARCH 2026
Velin
Started Velin, a custom new tab page with a clock, Pomodoro timer, to-do list and notepad, storing data in the browser with IndexedDB.
MARCH 2026
MarkdStudio
Started MarkdStudio, a browser-based Markdown editor.
JANUARY 2026 • THE LAUNCH
DayMark Goes Live
Developed and deployed DayMark — a real, live productivity web app. My first proper full-stack project shipped to the world. Still running at daymark.streamlit.app.
MID 11TH • THE AHA MOMENT
Hackathon from School to Zonal
I led my team in an All-India school-level hackathon. We cleared the school round and reached the Zonal level, placing in the top 120 nationwide. That was the moment I knew I wanted to keep building seriously.
🏅 Zonal Level
11TH STANDARD • THE COMEBACK
Python Done, Streamlit Added
I returned to Python and completed it properly. Then I discovered Streamlit and realized I could build real web apps using pure Python, which gave me strong momentum again.
10TH STANDARD • THE PAUSE
Board Exams Took Priority
I started a structured Python course, but 10th board exams demanded full focus. Coding had to pause for a while until academics settled down.
8TH–9TH STANDARD • THE DETOUR
Built a JARVIS Before Learning Python
I decided to build a Jarvis-style desktop assistant in Python before I properly knew the language. I followed YouTube tutorials line by line, and through that process I picked up Python syntax and kept improving my CSS skills too.
8TH STANDARD • THE BEGINNING
First Laptop Started the Journey
Got my first laptop in 8th, interest in technology, experience in Minecraft redstone and circuit, and problem-solving mindset was already there. And that problem-solving mindset naturally pulled me toward programming, and I started experimenting with HTML projects.
EARLIER • BEFORE 8TH
My interest and Minecraft
I was already interested in technology, figuring out how things work and all that. I was playing Minecraft (the cracked - pirated one) a lot back then. I liked working with redstone, which pulled my interest more into this tech field.
