# tahsin2155.github.io

Personal portfolio site for MD Tahsin Ali Abtahi.

This repository powers a casual, content-first portfolio that highlights my background, coding journey, skills, GitHub stats, and a few live projects.

## Live Site

Visit the portfolio here: https://tahsin2155.github.io

## What’s Inside

- Hero section with animated role text
- About section with short personal background
- Timeline of the coding journey
- Skills chips with brand and utility icons
- GitHub stats pulled from the GitHub API
- Featured project cards
- Contact links

## Tech Stack

- HTML
- CSS
- JavaScript
- Lucide icons
- Simple Icons assets
- GitHub REST API

## Notes

- The GitHub stats section depends on the public GitHub API.
- Some project and icon assets are loaded from external URLs.
- The site is intentionally lightweight and easy to edit in one file.
