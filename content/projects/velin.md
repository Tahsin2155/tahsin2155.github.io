# What it is

Velin is a custom new tab page. It replaces the default browser start page with something cleaner and more useful.

It is live at **newvelintab.netlify.app** and still in active development.


# Why I built it

The new tab page is the first thing I see every time I open a tab, so I wanted it to be something I would actually enjoy using.


# How it's built

- **Front end:** a web page hosted on Netlify
